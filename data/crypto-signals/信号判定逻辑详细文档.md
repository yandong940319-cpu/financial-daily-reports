## 1. 总览

本系统是**基于技术分析的币安交易信号生成器**，采用**双时间框架对齐策略**：

```
数据层 → 技术指标层 → 单TF信号检测 → 双TF对齐 → 仓位计算 → 信号输出
```

- **数据**: Binance K线数据 (200根蜡烛)
- **时间框架**: 15分钟 + 30分钟
- **输出**: LONG / SHORT 信号 (含入场价、止损、三级止盈、仓位)
- **通知**: 飞书消息推送
- **归档**: GitHub (financial-daily-reports 仓库)

## 3. 技术指标计算

共使用 **8种技术指标/工具**，分述如下：

### 3.1 SMA — 简单移动平均线

```python
sma(data, period)
```

- `period = 20, 50`
- 用于判断 MA 排列: `MA20 > MA50` (多头) / `MA20 < MA50` (空头)

### 3.2 EMA — 指数移动平均线

```python
ema_vals(data, period)
```

- MACD 计算依赖 EMA12 和 EMA26
- 平滑因子: `α = 2 / (period + 1)`

### 3.3 RSI — 相对强弱指数

```python
rsi(data, period=14)
```

| RSI 范围 | 判定 | 信号分 |
|----------|------|--------|
| `< 35` | **超卖** | +2 (买入) |
| `35-40` + 强趋势 | 偏低 | +1 (买入) |
| `> 75` | **超买** | +2 (卖出) |
| `60-75` + 强趋势 | 偏高 | +1 (卖出) |
| 其余 | 中性 | 0 |

### 3.4 ATR — 平均真实波幅

```python
atr(data, period=14)
```

- 用于**止损距离**和**仓位计算**
- 计算方式: 取过去14个TR的平均值
- `TR = max(High-Low, |High-PrevClose|, |Low-PrevClose|)`

### 3.5 ADX — 平均趋向指数

```python
adx(data, period=14)
```

| ADX 范围 | 判定 |
|----------|------|
| `< 20` | 震荡市 (无趋势) |
| `20-30` | 弱趋势 |
| `> 30` | **强趋势** |

**计算步骤**:
1. 计算 TR, +DM, -DM
2. 平滑 TR → ATR
3. 平滑 +DM 和 -DM → +DI, -DI
4. `DX = |+DI - -DI| / (+DI + -DI) × 100`
5. `ADX = SMA(DX, 14)`

### 3.6 布林带 (Bollinger Bands)

```python
bollinger(data, period=20)
```

- **中轨**: SMA(close, 20)
- **上轨**: 中轨 + 2σ
- **下轨**: 中轨 - 2σ

| 价格位置 | 判定 | 信号分 |
|----------|------|--------|
| 触碰/低于下轨 (`price ≤ 下轨×1.005`) | 超卖 | +1 (买入) |
| 触碰/高于上轨 (`price ≥ 上轨×0.995`) | 超买 | +1 (卖出) |

### 3.7 MACD — 指数平滑异同移动平均线

```python
macd(data)
```

- `EMA12` vs `EMA26` (约算)
- `MACD线 = EMA12 - EMA26`
- `信号线 ≈ MACD × 0.9` (简化算法)

| 关系 | 判定 | 信号分 |
|------|------|--------|
| MACD线 > 信号线 | **金叉** | +1 (买入) |
| MACD线 < 信号线 | **死叉** | +1 (卖出) |

### 3.8 OBV — 能量潮

```python
obv(data)
```

- 累计: 收盘涨 → 加成交量，收盘跌 → 减成交量
- 分割前后半段比较趋势方向
- 结果: "up" / "down" (辅助参考，不计分)

### 3.9 支撑阻力位

```python
support_resistance(data)
```

- 取最近60根K线
- **阻力位**: 最高3个高点的平均值
- **支撑位**: 最低3个低点的平均值
- 用于辅助参考

### 3.10 成交量分析

```python
volume_sma(data, period=20)
```

- `成交量比 = 最后1根成交量 / SMA(成交量, 20)`
- `成交量比 > 1.3` → **放量**
- 放量时，**增强当前信号方向** (+1分)

## 4. 单时间框架信号检测

函数: `detect_tf_signal(data, tf_name)`

### 4.1 评分系统

每个时间框架独立评分：

| 序号 | 指标 | 条件 | 买入分 | 卖出分 |
|------|------|------|--------|--------|
| 1 | 市场状态 | ADX > 20 (有趋势) | +说明 | - |
| | | ADX ≤ 20 (震荡) | - | +说明 |
| 2 | **RSI** | < 35 (超卖) | **+2** | 0 |
| | | > 75 (超买) | 0 | **+2** |
| | | 35-40 + 趋势 | +1 | 0 |
| | | 60-75 + 趋势 | 0 | +1 |
| 3 | **布林带** | 触下轨 | +1 | 0 |
| | | 触上轨 | 0 | +1 |
| 4 | **MACD** | 金叉 | +1 | 0 |
| | | 死叉 | 0 | +1 |
| 5 | **MA排列** | MA20 > MA50 | +1 | 0 |
| | | MA20 < MA50 | 0 | +1 |
| 6 | **成交量** | 放量(>1.3倍) + 增强主导方向 | +1 | +1 |

**总计**: 买入最多 **9分**，卖出最多 **9分**

### 4.2 判定阈值

```python
score = buy_signals - sell_signals
threshold = 4 if not is_trend else 3
```

| 条件 | 判定 |
|------|------|
| `score ≥ threshold` | **LONG** 信号 |
| `score ≤ -threshold` | **SHORT** 信号 |
| 其他 | **无信号** |

> **注意**: 震荡市阈值更高 (4)，趋势市阈值更低 (3)，因为在趋势市中更容易出现顺势信号。

### 4.3 置信度

```python
confidence = min(buy_signals / 9 * 100, 85)   # LONG
confidence = min(sell_signals / 9 * 100, 85)  # SHORT
```

- 上限 **85%**，避免过度自信

### 4.4 返回结构

```python
{
  "tf": "15m" / "30m",      # 时间框架
  "direction": "LONG" / "SHORT",
  "score": 整数,              # buy - sell 净分
  "confidence": 0-85,        # 置信度
  "reasons": ["RSI超卖(28)", "布林下轨", ...],  # 理由列表
  "rsi": 浮点数,
  "atr": 浮点数,
  "adx": 浮点数,
  "price": 浮点数,
  "sma20": 浮点数,
  "sma50": 浮点数,
  "vol_ratio": 浮点数,       # 成交量倍率
  "obv_trend": "up"/"down",
  "is_trend": bool           # 是否有趋势
}
```

## 5. 双TF对齐判定

函数: `check_signal(symbol)`

### 5.1 核心逻辑

```
1. 获取 15m K线 (200根) + 30m K线 (200根)
2. 各自独立调用 detect_tf_signal()
3. 判定条件（必须全部满足）:
   a) 两个TF都必须检测到信号（任一TF无信号 → 不出）
   b) 两个TF的方向必须一致（方向不一致 → 不出）
4. 通过后，生成最终信号
```

### 5.2 止损计算

```python
# 优先使用30m ATR（更宽，减少噪音扫损）
atr_final = sig_30m.atr or sig_15m.atr or price * 0.015

# 止损距离
stop_dist = max(atr_final × 1.8, price × 0.008)
```

| 参数 | 值 | 说明 |
|------|-----|------|
| ATR 倍数 | 1.8× | 回测优化值 |
| 最小止损 | 0.8% | 防止极端窄止损 |
| ATR 来源 | 优先30m | 更宽，抗噪音 |

### 5.3 止盈设置 (三级)

```python
TP1 = entry ± stop_dist × 1.5   # 第一目标
TP2 = entry ± stop_dist × 3.0   # 第二目标
TP3 = entry ± stop_dist × 5.0   # 第三目标
```

| 层级 | 风险回报比 | 说明 |
|------|-----------|------|
| TP1 | 1:1.5 | 第一目标 |
| TP2 | 1:3.0 | 主要目标 |
| TP3 | 1:5.0 | 终极目标 |

### 5.4 理由合并

- 合并 15m 和 30m 的入场理由
- **去重**: 按理由前缀去重 (如 "RSI超卖" 只出现一次，不管哪个TF)
- 最终理由是双TF的并集

### 5.5 最终置信度

```python
combined_confidence = (sig_15m.confidence + sig_30m.confidence) / 2
```

### 5.6 最终分数

```python
final_score = sig_15m.score + sig_30m.score
```

### 5.7 最终返回结构

```python
{
  "symbol": "BTCUSDT",
  "timeframe": "15m+30m",         # 双TF对齐
  "direction": "LONG"/"SHORT",
  "entry": 浮点数,                 # 当前价入场
  "stop_loss": 浮点数,
  "tp1": 浮点数,
  "tp2": 浮点数,
  "tp3": 浮点数,
  "position_size": 浮点数,         # 仓位数量
  "position_value": 浮点数,        # 仓位价值 ($)
  "risk_amount": 浮点数,           # 风险金额 ($)
  "confidence": 0-85,             # 合并置信度
  "score": 整数,                   # 合并评分
  "reasons": ["理由1", "理由2"],   # 去重理由
  "current_price": 浮点数,
  "atr": 浮点数,
  "rsi_15m": 浮点数,
  "rsi_30m": 浮点数,
  "adx_15m": 浮点数,
  "adx_30m": 浮点数,
  "vol_ratio": 浮点数,
  "obv_trend": "up"/"down",
  "sig_15m": {...},               # 15m原始信号
  "sig_30m": {...},               # 30m原始信号
  "expiry_hours": 6,             # 有效期
  "expiry_reason": "15m+30m信号超过6小时未触价则失效"
}
```

## 6. 仓位与风控

### 6.1 仓位计算

```python
ACCOUNT_SIZE = 15000     # 账户总资金 ($)
MAX_RISK = 200           # 单笔最大风险 ($)
MAX_POSITION_PCT = 25%   # 单笔最大仓位比例

risk_per = |entry - stop|                # 每单位风险
units = MAX_RISK / risk_per              # 基础仓位数量
value = units × entry                    # 仓位价值
if value > ACCOUNT_SIZE × 25%:           # 仓位上限25%
    units = (ACCOUNT_SIZE × 25%) / entry
    value = ACCOUNT_SIZE × 25%
```

| 参数 | 值 | 说明 |
|------|-----|------|
| 账户规模 | $15,000 | 虚拟账户 |
| 最大单笔风险 | $200 | 占总资金 1.33% |
| 最大仓位比例 | 25% | $3,750 上限 |

### 6.2 风控规则

| 规则 | 说明 |
|------|------|
| 已有活跃信号时不再产生新信号 | 同币种只允许一个活跃信号 |
| 信号有效期 6 小时 | 超时自动失效 |
| ATR 倍数止损 | 1.8×ATR，动态调整 |
| 三级止盈 | 逐步获利 |

## 7. 信号生命周期管理

### 7.1 状态流转

```
                    ┌─────────┐
                    │  active  │ ← 新建信号
                    └────┬─────┘
                         │
              ┌──────────┼──────────┐
              │          │          │
        未触价过期   触止损    触止盈
              │          │          │
         ┌────┴──┐  ┌───┴───┐  ┌───┴───┐
         │cancelled│ │stopped│  │tp1_hit│
         └────────┘  └───────┘  └───┬───┘
                                    │
                                继续监控
                              ┌──────┴──────┐
                              │tp2_hit      │→ 最终tp3_hit
                              └─────────────┘
```

### 7.2 状态判定

**活跃信号检查** (`check_active_signals`) 每轮扫描执行：

1. 获取当前价格
2. 检查是否触达止盈价或止损价
3. 逐级递进: active → tp1_hit → tp2_hit → tp3_hit
4. 直接触止损 → stopped
5. 超时(6h)未触价 → cancelled

### 7.3 盈亏计算

| 状态 | 盈亏计算 |
|------|---------|
| `stopped` | `-risk_amount` (全额亏损) |
| `tp1_hit` | `(tp1 - entry) × size × 30%` (部分止盈) |
| `tp2_hit` | 累积到tp2的盈亏 |
| `tp3_hit` | 全部目标完成 |
| `cancelled` | 盈亏为0 |

### 7.4 亏损反思

亏损信号自动生成反思，包含：
- 入场理由回顾
- 可能问题分析（止损太紧？趋势判断错误？逆势？）
- 改进方案

## 附录

### A. 评分卡速查

```
[1] 市场状态  ADX>20 → 有趋势    ADX≤20 → 震荡
[2] RSI       <35→+2买  35-40→+1买  >75→+2卖  60-75→+1卖
[3] 布林带    触下轨→+1买  触上轨→+1卖
[4] MACD      金叉→+1买  死叉→+1卖
[5] MA排列    MA20>MA50→+1买  MA20<MA50→+1卖
[6] 成交量    放量>1.3倍→主导方向+1

总分 = 买入分 - 卖出分
趋势市: ≥3 出LONG, ≤-3 出SHORT
震荡市: ≥4 出LONG, ≤-4 出SHORT
```

### B. 止损止盈公式速查

```
LONG:  止损 = entry - max(atr×1.8, price×0.008)
       TP1   = entry + stop_dist × 1.5
       TP2   = entry + stop_dist × 3.0
       TP3   = entry + stop_dist × 5.0

SHORT: 止损 = entry + max(atr×1.8, price×0.008)
       TP1   = entry - stop_dist × 1.5
       TP2   = entry - stop_dist × 3.0
       TP3   = entry - stop_dist × 5.0
```

### C. 仓位速查

```
units = 200 / |entry - stop|
value = units × entry
if value > 3750: units = 3750 / entry
```
