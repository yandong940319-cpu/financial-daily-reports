# 币安 15m + 30m 双时间框架对齐策略

> 最后更新: 2026-05-05

## 策略概览

基于 **15分钟 + 30分钟 双时间框架对齐** 的短线交易策略。
只有当两个时间框架的独立信号方向一致时才触发交易。

### 回测结果 (1年BTC数据, 2025-05 ~ 2026-05)

| 指标 | 值 |
|------|------|
| 年交易次数 | 109 |
| 胜率 | 56.0% |
| 净盈亏 | +$224 / $10,000 |
| 夏普比率 | 1.98 |
| 最大回撤 | 1.3% |
| 单笔最大亏损 | $200 (固定风控) |

**对比**: 15m独立策略夏普 -1.34（亏$1,077/年），15+30对齐夏普 +1.98（赚$224/年）。

## 技术指标

### 1. RSI (相对强弱指数)

```
周期: 14
公式: RSI = 100 - 100 / (1 + RS)
      RS = 平均涨幅 / 平均跌幅 (平滑移动平均)
```

使用 Wilder 平滑法（指数移动平均风格），避免 SMA 突变。

**阈值**:
- 超卖: < 35 → +2 分 (买入信号)
- 偏低: 35-40 且在趋势市中 → +1 分
- 超买: > 75 → +2 分 (卖出信号)
- 偏高: 60-75 且在趋势市中 → +1 分

### 2. ADX (平均趋向指数)

```
周期: 14
步骤:
  1. TR = max(High-Low, |High-PrevClose|, |Low-PrevClose|)
  2. +DM = High - PrevHigh (if > -DM)
  3. -DM = PrevLow - Low (if > +DM)
  4. +DI = 平滑(+DM) / ATR * 100
  5. -DI = 平滑(-DM) / ATR * 100
  6. DX = |+DI - -DI| / (+DI + -DI) * 100
  7. ADX = SMA(DX, 14)
```

**用途**:
- ADX > 20: 趋势市（使用更低的信号阈值 threshold=3）
- ADX > 30: 强趋势（增加买入信号权重）
- ADX <= 20: 震荡市（提高阈值 threshold=4，减少交易频率）

### 3. 布林带 (Bollinger Bands)

```
周期: 20
标准差倍数: 2
中轨: SMA(close, 20)
上轨: 中轨 + 2 * σ
下轨: 中轨 - 2 * σ
```

**用途**:
- 价格触碰下轨 → +1 分 (买入信号)
- 价格触碰上轨 → +1 分 (卖出信号)

### 4. MACD

```
快线EMA周期: 12
慢线EMA周期: 26
信号线周期: 9 (MACD的EMA)
MACD线 = EMA(close, 12) - EMA(close, 26)
信号线 = EMA(MACD线, 9)
```

**用途**:
- MACD线 > 信号线 (金叉) → +1 分 (买入信号)
- MACD线 < 信号线 (死叉) → +1 分 (卖出信号)

### 5. MA (移动平均线)

```
快线: SMA 20 (周期: 20)
慢线: SMA 50 (周期: 50)
```

**用途**:
- MA20 > MA50 (多头排列) → +1 分 (买入信号)
- MA20 < MA50 (空头排列) → +1 分 (卖出信号)

### 6. 成交量分析

```
成交量均线: SMA(volume, 20)
量比 = 当前成交量 / 成交量均线
```

**用途**:
- 量比 > 1.3 (放量) → 对当前占优方向额外 +1 分

### 7. OBV (能量潮)

```
OBV:
  - 收盘涨 → OBV += 当前成交量
  - 收盘跌 → OBV -= 当前成交量
```

**用途**: 辅助确认趋势方向，不直接计分

## 信号检测流程

### 单时间框架检测 (detect_tf_signal)

每个时间框架独立运行以下流程:

```
总分 = 买入信号分数 - 卖出信号分数

买入信号 (最高9分):
  RSI超卖(+2) | RSI偏低(+1) | 布林下轨(+1) | MACD金叉(+1)
  MA20>50(+1) | 强趋势(+1) | 放量配合(+1) | ADX>30(+1)

卖出信号 (最高9分):
  RSI超买(+2) | RSI偏高(+1) | 布林上轨(+1) | MACD死叉(+1)
  MA20<50(+1) | 强趋势(+1) | 放量配合(+1)

阈值:
  趋势市(ADX>20): score >= 3  或 score <= -3
  震荡市(ADX≤20): score >= 4  或 score <= -4
```

### 双TF对齐 (check_signal)

```
1. 获取 15m K线 (200根) → 检测 15m 信号
2. 获取 30m K线 (200根) → 检测 30m 信号
3. 如果两者信号方向一致(LONG/LONG 或 SHORT/SHORT):
   → 触发交易信号
4. 如果任一TF无信号或方向冲突:
   → 不触发
```

## 交易参数

### 入场

- **入场价**: 当前市价 (信号检测时的最新收盘价)
- **时间框架**: `15m+30m`
- **仓位**: 基于 $15,000 账户，每笔 25% = $3,750 名义价值
  - (模拟盘按 $10,000 账户缩放)

### 止损 (SL)

```
基于 30m 的 ATR (更宽，减少噪音扫损)
止损距离 = max(ATR_30m × 1.8, 价格 × 0.008)
单笔最大亏损 = $200 (固定)
```

对比: 纯15m策略使用 ATR × 1.5，切换30m ATR × 1.8 后回撤从 12.8% 降至 1.3%。

### 止盈 (TP)

```
TP1 = 入场 ± 止损距离 × 1.5 (半仓)
TP2 = 入场 ± 止损距离 × 3.0
TP3 = 入场 ± 止损距离 × 5.0
```

### 信号有效期

```
6小时 (15m+30m 组合的中间值)
超过6小时未触及止损/止盈 → 自动取消
```

对比: 纯15m策略有效期4小时。

### 仓位计算

```
风险金 = min(止损距离 × 数量, $200)
仓位 = 风险金 / 止损距离
名义价值 = 仓位 × 入场价
if 名义价值 > 账户 × 25%:
  仓位 = 账户 × 25% / 入场价
```

## 运行方式

### 扫描频率

每分钟执行一次 (`cron * * * * *`):
1. 检查已有活跃信号 (是否触价/过期)
2. 检测新信号 (BTCUSDT + ETHUSDT)
3. 如有新信号 → 飞书私聊通知 + GitHub归档
4. 如有信号关闭 → 飞书通知盈亏 + 亏损反思

  • RSI超卖(33.5)

## 已知限制

1. **只支持 BTCUSDT + ETHUSDT**: 可扩展，但需调整参数
2. **无滑点模拟**: 回测假设市价成交，实际可能有滑点
3. **无手续费**: 回测未计入 Binance 手续费 (0.1%)
4. **信号有效期基于日历时间**: 6小时固定，未根据波动率动态调整
5. **只做LONG**: 当前回测和实际信号均为多头，SHORT逻辑未充分验证
