# 币安 15m + 30m 状态切换策略 (v4)

> 最后更新: 2026-05-05

## 策略概览

基于 **1小时ADX市场状态判断 + 15分钟/30分钟双时间框架** 的自适应交易策略。

核心思想——**没有全局最优策略，只有适合当前市场的策略**：

| 市场状态 | 使用策略 | 逻辑 |
|:--|:--|:--|
| 震荡 (1h ADX < 25) | **alignment** (双TF对齐) | 15m+30m同时出信号且方向一致才交易，高精度过滤假信号 |
| 趋势 (1h ADX >= 25) | **division** (分工) | 30m MA20/MA50定方向偏向，15m RSI/布林/MACD找入场点，捕捉早期突破 |

### 回测结果 (3年BTC数据, 2023-05 ~ 2026-05)

三种策略对比：

| 策略 | 交易/年 | 胜率 | 净盈亏(3年) | 夏普 | 最大回撤 |
|:--|:--:|:--:|:--:|:--:|:--:|
| **状态切换** ✅ | **84** | **62.5%** | **+$1,672** | **3.99** | **1.3%** |
| 纯alignment | 91 | 61.7% | +$1,686 | 3.66 | 1.3% |
| 纯分工(MA bias) | 145 | 60.3% | +$1,758 | 3.04 | 1.5% |
| 15m独立 | 398 | 56.5% | -$3,968 | -1.67 | 14.2% |

### 策略对比维度

| 维度 | alignment | 分工 | 状态切换 |
|:--|:--:|:--:|:--:|
| 信号质量 | 高 | 中 | **最高** |
| 胜率 | 高 | 中 | **最高** |
| 交易频率 | 低 | 中 | **最低** |
| 趋势捕捉 | ❌ 滞后 | ✅ 强 | **自适应** |
| Sharpe上限 | 3.66 | 3.04 | **3.99** |

## 技术指标 (detect_tf_signal)

每个时间框架独立运行相同的评分系统：

### 评分规则

| 指标 | 条件 | 分数 |
|:--|:--|:--:|
| **ADX** (趋势强度) | ADX > 30 | +1 市场偏多 |
| | ADX ≤ 20 | +1 市场偏空 |
| **RSI** (超买超卖) | < 35 (超卖) | **+2** |
| | > 75 (超买) | **-2** |
| | 35-40 且趋势市中 | +1 |
| | 60-75 且趋势市中 | -1 |
| **布林带** | 触碰下轨 | +1 |
| | 触碰上轨 | -1 |
| **MACD** | 金叉 | +1 |
| | 死叉 | -1 |
| **移动平均线** | MA20 > MA50 | +1 |
| | MA20 < MA50 | -1 |
| **成交量** | 放量且已有偏向 | +1 (放大) |

### 触发阈值

| 市场状态 | 阈值 |
|:--|:--:|
| 趋势市 (ADX > 20) | score >= **3** |
| 震荡市 (ADX ≤ 20) | score >= **4** |

### 成交量过滤器 (v4新增)

```
if vol_ratio < 1.0 and abs(score) >= 3:
    skip_signal  # 缩量不出信号
```

原理：成交量是**确认信号**不是**决策信号**。低量说明市场缺乏参与度，即使指标触发信号可信度也不足。

> 细节博弈: 最初尝试"放量上涨=强多+2分"，结果回测变差。原因是大佬指出的——把"成交量当成了方向信号"（方向由价格结构决定，成交量只确认强度）。最终最佳方案是保留"放大现有偏向"的逻辑 + 增加低量过滤。

## 信号检测流程 (check_signal v4)

```
1. 获取 15m + 30m + 1h K线
2. 计算 1h ADX 判断市场状态
3. 分支:
   ┌─ ADX < 25 ──────────────────────┐
   │ 震荡模式: alignment              │
   │ 15m信号 AND 30m信号 方向一致 → 交易 │
   └──────────────────────────────────┘
   ┌─ ADX >= 25 ─────────────────────┐
   │ 趋势模式: division               │
   │ 30m MA20>MA50 → LONG bias       │
   │ 30m MA20<MA50 → SHORT bias      │
   │ 15m信号匹配 bias方向 → 交易       │
   └──────────────────────────────────┘
```

### 关键设计决策

**为什么alignment在震荡市胜出？**
- 30m是低频噪音过滤器
- 两个TF同时同意才出手 = 高精度过滤假信号 (precision ↑, recall ↓)
- 在震荡市中假信号多，alignment价值最大

**为什么分工在趋势市更好？**
- 30m MA方向判断比30m评分系统更早捕捉趋势
- 30m刚出趋势但评分系统还没确认时，15m已提前突破
- 分工模式捕捉早期入场，RR更好
- 3年数据验证: 趋势市占47%，震荡市占39%

## 交易参数

### 入场

- **入场价**: 当前市价
- **模式标记**: `15m+30m(对齐/震荡)` 或 `15m+30m(分工/趋势)`
- **仓位**: $10,000 模拟盘 × 25% = $2,500/笔

### 止损 (SL)

```
止损距离 = max(ATR_30m × 1.8, 价格 × 0.008)
单笔最大亏损 = $200 (固定)
```

使用30m ATR × 1.8（比15m的1.5x更宽），减少噪音扫损。

### 止盈 (TP)

```
TP1 = 入场 ± 止损距离 × 1.0  → 全仓
TP2 = 入场 ± 止损距离 × 2.0
TP3 = 入场 ± 止损距离 × 3.0
```

TP1设置1.0R而非1.5R：当前系统信号以均值回归为主（RSI/布林），均值回归信号不宜设远止盈。1.5R导致胜率从55.8%暴跌至35.6%。

### 信号有效期

```
6小时
超过未触及止损/止盈 → 自动取消
```

## 已知限制

1. **只支持BTCUSDT+ETHUSDT**: 参数针对BTC优化，ETH需单独回测
2. **无滑点/手续费**: 回测未计入，实际可能降低5-10%收益
3. **1h ADX作为唯一状态判断**: 可改用FreqAI做ML状态检测
4. **只做LONG**: SHORT逻辑未充分验证
5. **单一币种仓位**: 不支持多币种同时持仓
